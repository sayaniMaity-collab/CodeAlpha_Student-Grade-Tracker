# CodeAlpha_Student-Grade-Tracker
A console-based Java application that manages student grades using ArrayList and calculates the average, highest, and lowest scores. It generates a simple summary report of all students.
The Student Grade Tracker is a console-based Java application developed to manage and analyze student grades. The program allows users to enter student names and their grades and stores the information using ArrayList.
The application calculates the average, highest, and lowest grades and displays all student information in a clear summary report. This project demonstrates the use of Java concepts such as ArrayList, loops, conditional statements, user input, and basic data processing.
